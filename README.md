# 섹터 자금흐름 대시보드

빅테크 / 반도체 / 소프트웨어 / 금융 / 2차전지·에너지 / 헬스케어 섹터의 자금흐름과 뉴스 언급량을 추적해서, 과도한 하락이 매수 관점이었는지 돌아보고 뉴스가 뜨기 전에 선제적으로 흐름을 포착하는 걸 목표로 하는 대시보드.

프레임워크 없음. 순수 HTML/CSS/JS 정적 사이트, GitHub Pages 배포 대상.

## 화면 구성
- **섹터 자금흐름**: 섹터별 카드(순매수 추정, 등락, 대표종목) — 클릭 시 종목별 상세 + 관련 뉴스 모달
- **하락 히스토리**: 과도하게 빠진 날의 헤드라인 + 이후 흐름(돌아보면 매수 기회였는지) 타임라인
- **선제 신호**: 자금흐름 변화율과 뉴스 언급량 변화율의 괴리를 계산해서, 뉴스가 뜨기 전에 자금이 먼저 움직이는 섹터를 표시

## 현재 상태
`app.js`의 `SECTORS` / `EVENTS`는 전부 샘플 데이터. 화면 상단 배너로 "샘플 데이터"임을 항상 표시함.

## 다음 단계 (실 데이터 연동)
1. 네이버금융(시세/수급) + 네이버 뉴스 검색 API를 Google Apps Script가 주기적으로 수집해서 시트/DB에 캐싱 (accounting-app의 `Code.gs` 백업 구조 참고)
2. `app.js`에 `fetchSectorData()` / `fetchDropEvents()` 같은 async 함수를 추가해서 GAS 웹앱 엔드포인트를 호출, 지금의 `SECTORS` / `EVENTS` 배열을 그 결과로 채우기
3. 필드명(`netFlow`, `flowChangePct`, `newsVolume`, `newsChangePct`, `changePct`, `flow` 등)은 그대로 유지하면 렌더링 코드 수정 없이 실데이터로 교체 가능
