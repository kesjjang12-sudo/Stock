# 섹터 자금흐름 대시보드

빅테크 / 반도체 / 소프트웨어 / 금융 / 2차전지·에너지 / 헬스케어 섹터의 자금흐름과 뉴스 언급량을 추적해서, 과도한 하락이 매수 관점이었는지 돌아보고 뉴스가 뜨기 전에 선제적으로 흐름을 포착하는 걸 목표로 하는 대시보드.

프레임워크 없음. 순수 HTML/CSS/JS 정적 사이트, GitHub Pages 배포 대상.

## 화면 구성
- **섹터 자금흐름**: 섹터별 카드(순매수 추정, 등락, 대표종목), 정렬(자금유입순/변화율순/뉴스언급순) — 클릭 시 종목별 상세 + 관련 뉴스 모달
- **하락 히스토리**: 과도하게 빠진 날의 헤드라인 + 이후 흐름(돌아보면 매수 기회였는지) 타임라인
- **선제 신호**: 자금흐름 변화율과 뉴스 언급량 변화율의 괴리를 계산해서, 뉴스가 뜨기 전에 자금이 먼저 움직이는 섹터를 표시
- 모바일(≤640px)에서는 하단 탭바로 전환

## 데이터 연동 (Google Apps Script + 네이버)
`Code.gs`가 네이버금융(국내 시세·외국인/기관 수급) + 네이버 뉴스 검색 API를 10분 주기로 수집해서 구글 시트에 캐싱하고, 프론트가 그 결과를 fetch 해온다.

**배포 방법**
1. https://script.google.com → 새 프로젝트 → `Code.gs` 내용 붙여넣기
2. 프로젝트 설정(⚙️) → 스크립트 속성에 추가
   - `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` — https://developers.naver.com/apps 에서 "검색" API로 애플리케이션 등록 후 발급 (뉴스 언급량 집계용, 없으면 시세/수급만 동작)
3. 함수 목록에서 `setupTrigger` 실행 (최초 1회, 권한 승인 필요) → 10분마다 자동 갱신 트리거 등록
4. 배포 → 새 배포 → 웹앱 (실행: 나 / 액세스: 모든 사용자) → 생성된 URL 복사
5. 대시보드 우상단 ⚙️ 설정 → 웹앱 URL + `Code.gs`의 `SECRET_KEY` 값 입력 → 저장

연동 전에는 자동으로 샘플 데이터(DEMO 배너)로 동작하고, 연동 후 서버 오류가 나면 마지막으로 받은 데이터로 폴백한다.

## 알림 (웹페이지)
하락(-2.5% 이하)이나 선제 신호가 감지되면 **알림 탭**에 자동으로 쌓인다.
- 안 읽은 알림은 탭에 빨간 뱃지로 표시되고, 알림 탭을 보면 읽음 처리된다
- 같은 날 같은 사유로는 중복 기록하지 않고, 한 번 실행에 최대 3건까지만 (초과분은 다음 회차로 이월)
- ⚙️ 설정에서 **브라우저 알림**을 허용하면 탭이 뒤에 있어도 새 신호를 알려준다
  (아이폰은 홈 화면에 추가한 경우에만 동작)

알림 기록은 카카오 연동 여부와 무관하게 항상 `AlertLog` 시트에 쌓인다.

## 카카오톡 알림 (선택)

> 카카오톡은 **단톡방/오픈채팅방에 봇을 넣는 공식 API가 없다.** 공식 메시지 API는
> "나에게 보내기"와 친구 1:1 전송만 지원한다. 단톡방 알림이 필요하면 텔레그램·디스코드
> 그룹 봇을 쓰거나, 그냥 위의 웹 알림 탭을 쓰면 된다.

과도한 하락(-2.5% 이하)이나 선제 신호가 감지되면 카톡 "나에게 보내기"로 알림이 온다.
같은 날 같은 사유로는 중복 발송하지 않고, 한 번 실행에 최대 3건까지만 보낸다.

**설정 (최초 1회)**
1. https://developers.kakao.com → 애플리케이션 추가하기
2. [앱 키]의 **REST API 키** 복사 → GAS 스크립트 속성에 `KAKAO_REST_KEY`로 저장
3. [제품 설정 > 카카오 로그인] 활성화 ON
4. GAS에서 `showKakaoSetup` 함수 실행 → 로그에 찍힌 Redirect URI를
   [카카오 로그인 > Redirect URI]에 그대로 등록
5. [카카오 로그인 > 동의항목]에서 **카카오톡 메시지 전송(talk_message)** 사용 설정
6. 대시보드 ⚙️ 설정 → **카톡 알림 연결** 클릭 → 카카오 로그인 → 끝

OAuth 콜백을 GAS 웹앱이 직접 받으므로 인증 코드를 수동으로 복사할 필요가 없다.
액세스 토큰(6시간)은 갱신 트리거가 돌 때마다 리프레시 토큰으로 자동 재발급된다.

> 본인에게 보내는 "나에게 보내기"는 카카오 검수 없이 바로 된다.
> 다른 사람에게 보내려면 카카오 검수가 필요하다.

## 데이터의 한계 (중요)
- 외국인·기관 수급은 **국내 상장 종목 기준**으로만 계산됨 (미국 종목은 이런 공개 수급 데이터가 없음)
- 무료 소스 특성상 수급은 실시간이 아니라 **당일 장중~전일 반영** 수준
- "선제 신호"는 통계적 확신이 아니라 자금/뉴스 변화율의 단순 괴리 지표 — 참고용
